# Security Policy

## Reporting Security Issues

Xue Studios LLC takes the security of its software projects, cloud infrastructure, and open media specifications very seriously.

If you believe you have discovered a security vulnerability in any project, library, specification, or service developed by Xue Studios LLC, **please do not report it in public GitHub issues or discussions**.

### How to Report

Please submit security vulnerability disclosures responsibly directly to:

- **Email**: [support@oim.media](mailto:support@oim.media) or [security@xuestudios.com](mailto:security@xuestudios.com)
- **Subject**: `[SECURITY DISCLOSURE] - <Project Name> - <Brief Description>`

Please include in your report:
1. Detailed description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal proof of concept (PoC).
3. The affected project, repository, or service.

### Response Timeline

- **Acknowledgment**: Within 48 hours of receipt.
- **Initial Assessment**: Within 5 business days.
- **Remediation & Coordination**: We will coordinate with you regarding the timeline for deploying a patch prior to any public disclosure.

Thank you for helping us keep Xue Studios LLC software safe and resilient for everyone.
